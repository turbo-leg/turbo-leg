### ⭐ Highlights

#### 🃏 [Durak](https://github.com/turbo-leg/Durak) · [play it](https://durak-discord-activity.fly.dev)
Real-time multiplayer Durak card game that runs **inside Discord voice calls** as a Discord Activity.
- Server-authoritative game state on Colyseus, with hands and deck order filtered per player and verified session tokens
- Interactive **Three.js card table** with a 2D fallback, plus bots and achievements for 2–6 players
- 290+ commits, 50+ test files, CI, and Docker/Fly.io deploys

`TypeScript` `Colyseus` `React` `Three.js` `MongoDB` `Redis`

#### 🎓 Primis · [live portal](https://primis-portal.vercel.app) <sub>(private repo)</sub>
Production IELTS/SAT prep portal for a tutoring center in Mongolia, with **student, teacher, parent and admin** roles.
- Google sign-in for students, and phone-code sign-in for parents (Verify.MN / Twilio)
- Rotating QR codes link a parent to their child without needing an admin
- Courses, enrollments, attendance, excuses, payment deadlines, web push and Google Classroom integration
- Mobile apps built with Capacitor, in English and Mongolian
- 190+ commits, 50+ test files, CI, Sentry monitoring and rate limiting

`Python` `FastAPI` `PostgreSQL` `SQLAlchemy` `Redis` `Nuxt 4` `Capacitor`

#### 🀄 Muushig · [play it](https://muushig.fly.dev) <sub>(private repo)</sub>
Mongolia's classic trick-taking card game as a Discord Activity.
- Pure, fully tested rules engine shared between client and server
- Bots, reconnection, spectators, private tables, **Elo ratings and a leaderboard**, a bilingual rules book, and generative tavern music

`TypeScript` `Colyseus` `React` `Fly.io`
